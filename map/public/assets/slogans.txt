# mampf-Sprüche
#
# Bei jedem Laden des Logos wird zufällig einer dieser Sprüche
# unter das Logo geschrieben (Splashscreen, About-Seite, Login).
#
# - Ein Spruch pro Zeile, am besten kleingeschrieben (die Schrift hat nur
#   Kleinbuchstaben). Erlaubt sind: a-z ä ö ü é è à 0-9 ? ! . , : - ' " /
# - Lange Sprüche werden automatisch kleiner, damit sie vor das «p» passen.
#   Ab etwa 16 Zeichen wird es merklich kleiner.
# - Zeilen mit # am Anfang und leere Zeilen werden ignoriert.
# - Ausprobieren, wie ein neuer Spruch aussieht: design/font/testen.html
